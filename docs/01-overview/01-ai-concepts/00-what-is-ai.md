# AI 是什么（入门）

> 用大白话讲清楚 AI 到底是什么，不需要任何技术背景

## 一句话解释 AI

**人工智能（Artificial Intelligence，简称 AI）** 就是让计算机模拟人类的思考和学习能力，去完成原本需要人类智能才能做的事情。

你可能每天都在使用 AI，只是没意识到：

| 场景 | AI 在做什么 | 涉及技术 |
| --- | --- | --- |
| 打开抖音/快手 | 推荐算法在猜你喜欢什么视频 | 推荐系统 |
| 用手机拍照 | 自动美颜、识别场景优化画质 | 计算机视觉 |
| 语音助手（Siri/小爱） | 听懂你说的话并执行指令 | 语音识别 + NLP |
| 淘宝/京东购物 | 根据浏览历史推荐商品 | 推荐系统 |
| 高德/百度地图 | 实时计算最优路线 | 路径规划 |
| 人脸识别解锁/支付 | 识别你的脸 | 人脸识别 |
| ChatGPT/Kimi 对话 | 理解你的问题并生成回答 | 大语言模型 |
| AI 生成图片/视频 | 根据描述创造全新内容 | 生成式 AI |

## AI 的三个层次

```
弱人工智能（Narrow AI / ANI）
├── 只能做特定任务（如语音助手、推荐算法）
├── 在特定领域可能超越人类
└── ← 我们现在所有 AI 都在这里

强人工智能（General AI / AGI）
├── 能像人一样处理任何类型的问题
├── 具有真正的理解和学习能力
└── ← 尚未实现

超级人工智能（Super AI / ASI）
├── 在所有方面都超越人类的智能
└── ← 纯理论/科幻概念
```

## AI 不是什么

| 误区 | 事实 |
| --- | --- |
| AI 像人一样"思考" | AI 在做复杂的数学运算和模式匹配 |
| AI 有"意识" | AI 没有情感、没有自我意识 |
| AI 是万能的 | AI 在训练数据之外的领域能力有限 |
| AI 完全可靠 | AI 会犯错，需要人类审核 |

## 为什么 AI 现在突然火了？

三个条件同时成熟了：

1. **数据量爆发** — 互联网产生了海量训练数据
2. **算力大幅提升** — GPU 让训练大模型成为可能
3. **算法突破** — Transformer 架构带来质的飞跃

## 核心概念地图

本目录的子文档围绕下面这张概念地图展开：

```
Transformer（底座架构，2017 年提出）
   └─ 训练出 → LLM（大语言模型）
                ├─ 通过 Prompt（提示词）交互，按 Token 计量/计费
                ├─ 上下文窗口限制一次能"看到"的内容
                ├─ 多模态扩展（文本/图片/音频/视频）
                ├─ 向量化（Embedding）支撑语义检索
                └─ + 工具/记忆/规划 → AI Agent（智能体）
```

| 概念 | 一句话解释 | 详见 |
| --- | --- | --- |
| Transformer | 几乎所有现代大模型的底座，核心是注意力机制（Attention） | [理解 AI 模型](../02-ai-models.md) |
| LLM | "读了互联网几乎所有文字"的 AI，学会语言规律后能理解问题、生成回答 | [LLM 与 Token](01-llm-and-token.mdx) |
| Token | AI 处理文字的最小单位，决定计费、长度上限与速度 | [LLM 与 Token](01-llm-and-token.mdx) |
| Prompt | 你给 AI 的指令，同一任务不同 Prompt 结果天差地别 | [提示词工程](../03-prompt-engineering.md) |

| AI Agent | 从一问一答进化到自主规划、使用工具、完成复杂任务 | 见下文速览 |

### Prompt 五要素速览

一个完整的 Prompt 通常包含：

```
├── 角色（Role）    → 你希望 AI 扮演什么角色？
├── 任务（Task）    → 你希望 AI 做什么？
├── 要求（Format）  → 有什么具体要求？
├── 约束（Rule）    → 有什么限制条件？
└── 示例（Example） → 能给个参考吗？
```

### AI Agent 速览

传统 AI 只能一问一答；AI Agent 能自主规划、使用工具、完成复杂任务：

```
AI Agent = LLM（大脑）+ 工具（手脚）+ 记忆（经验）+ 规划（策略）
```

例如给它一个目标"帮我调研竞品"，它会自动拆解步骤：上网搜索 → 逐个收集信息 → 整理对比表 → 生成分析报告。

### 训练 vs 推理速览

| 对比 | 训练 | 推理 |
| --- | --- | --- |
| 类比 | 上学学习 | 考试答题 |
| 频率 | 一次（或定期更新） | 每次对话都在推理 |
| 时间 | 数月 | 几秒 |
| 成本 | 极高（亿美元级） | 较低（每次几分钱） |
| 谁在做 | AI 公司 | 每个用户 |

## 小结

AI 不是魔法，而是一种**工具**。就像电和互联网一样，它会逐渐成为生活和工作中无处不在的一部分。了解它、学会用它，是这个时代最实用的技能之一。

> **关键认知**：AI 不会取代人类，但**会用 AI 的人**可能会取代**不会用 AI 的人**。
